# Fonts

- `ArchivoBlack-Regular.ttf`: Archivo Black by Omnibus-Type, SIL Open Font License 1.1. Used for every display label, score, and button title.
- `Archivo-Variable.ttf`: Archivo (variable `wdth`,`wght`) by Omnibus-Type, SIL Open Font License 1.1. Used at weight 600 and 700 for body copy, settings labels, tips, and captions.

Both faces are bundled so the interface renders identically on macOS captures and on iPhone. See `THIRD_PARTY_NOTICES.md` and `LICENSES/`.
