# Orbit Breaker audio

`music_base.wav` and `music_drive.wav` are original adaptive music layers generated by `tools/generate_audio_assets.py`.

The short gameplay and interface effects are selected from Kenney's CC0 Sci-Fi Sounds 1.0 and Interface Sounds 1.0 packs, then converted from OGG Vorbis to PCM WAV for deterministic headless Godot loading. Exact source-file mappings and license links are recorded in `THIRD_PARTY_NOTICES.md`.

Do not replace the five authored effects by running the music generator. The generator intentionally writes only the two original music layers.
